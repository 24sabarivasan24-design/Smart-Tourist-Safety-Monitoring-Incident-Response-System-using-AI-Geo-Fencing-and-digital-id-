# SafeTour India — GitHub Deployment

This package is prepared for static hosting such as GitHub Pages.

## Files
- `index.html` — complete SafeTour India application
- `manifest.json` — PWA manifest referenced by the app
- `sw.js` — service worker referenced by the app
- `.nojekyll` — prevents GitHub Pages Jekyll processing

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and **/ (root)**.
6. Save and open the generated Pages URL.
