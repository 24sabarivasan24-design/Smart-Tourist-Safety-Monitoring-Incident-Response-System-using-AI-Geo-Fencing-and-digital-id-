# Movie Ticket Booking – GitHub Deployment

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` branch and `/ (root)`.
6. Click **Save**.
7. GitHub will provide the live website URL.

This project is a static website, so no Node.js, npm, or `package.json` is required for GitHub Pages deployment.
